Tema modern nuansa hijau dingin untuk situs MAN 3 Jember.

== Description ==

Tema WordPress yang memuat desain landing page hijau dingin (brand kuat, hero full-bleed, tipografi Fraunces + Outfit) dengan konten yang sama dari situs publik MAN 3 Jember. Berita diambil dari post WordPress jika ada; jika belum, memakai fallback konten publik.

== Installation ==

1. Di wp-admin: Appearance → Themes → Add New → Upload Theme
2. Pilih file zip `man3-hijau-dingin.zip`
3. Install lalu Activate
4. Opsional: Appearance → Menus — assign menu ke lokasi "Menu Utama"
5. Opsional: Appearance → Customize → Site Identity — set judul "MAN 3 JEMBER" dan tagline "Cerdas Kreatif"

== Frequently Asked Questions ==

= Apakah konten lama hilang? =

Tidak. Post, halaman, dan media di WordPress tetap ada. Tema hanya mengubah presentasi. Menu yang sudah ada bisa di-assign ke lokasi tema.

= Ukuran upload zip terlalu besar? =

Ekstrak zip lalu upload folder `man3-hijau-dingin` lewat File Manager / FTP ke `wp-content/themes/`, lalu aktifkan di Appearance → Themes.
